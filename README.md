# متجر MT UAE FANS

ملفات المتجر:
- index.html  : هيكل الصفحة
- style.css   : الألوان والتصميم (أسود + أحمر + ذهبي)
- products.json : المنتجات (غيّر الاسم/السعر من هنا بس)
- app.js      : السلة وربط الدفع
- api/checkout.js : صفحة الدفع (Stripe) على Vercel
- success.html : صفحة "تم الدفع"

المنتجات الموجودة حاليًا أمثلة، استبدلها بمنتجاتك الحقيقية.
